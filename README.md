# GDG on Campus UGM — Frontend Assignment

A responsive, multi-page landing website for **Google Developer Groups on Campus (GDGOC) UGM**, developed as part of the GDGOC Frontend Assignment.

**Live Demo:** https://gdgoc-frontend-assignment.vercel.app/

## ✨ Features

- **Responsive Design** — Adapts to desktop, tablet, and mobile screens.
- **Multi-page Navigation** — Separate pages for Landing, About, Overview, and Contact.
- **Interactive FAQ** — Expandable FAQ sections.
- **Reusable Components** — Modular components for consistent layouts.
- **Smooth Navigation** — Navigation links for accessing different sections.
- **Modern UI** — Clean interface built with Tailwind CSS.

## 🛠️ Tech Stack

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:
- [Node.js](https://nodejs.org/)
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/IceBearVenom/GDGoC-Frontend-Assigment.git
   ```

2. Navigate to the project directory:

   ```bash
   cd GDGoC-Frontend-Assigment
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL provided by Vite in your browser.

## 📦 Available Scripts

| Command | Description |
|---|---|
| `npm run dev` | Starts the development server |
| `npm run build` | Runs TypeScript checks and builds the production version |
| `npm run preview` | Previews the production build locally |
